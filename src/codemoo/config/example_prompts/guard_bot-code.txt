Create a new directory tiemit/ and initialize it as a uv project with `uv init`.
Then create a CLI string reversal challenge game with these requirements:

1. Generate a random string of 5-10 lowercase letters.
2. Display the string and start a timer.
3. Ask the user to type the reversed string.
4. Stop the timer when the user submits.
5. Simulate an AI opponent: 30% chance of correct reversal, 70% chance of failure.
6. Show: user's time, user's answer, AI's answer, correct answer, and who won (user, AI, or tie).
7. Ask if the user wants to play again.

Use only print() and input() — no external libraries.
